# Relatório de Isolamento de Problema – Computador Lento

Este repositório contém um relatório técnico elaborado a partir de uma
experiência prática em suporte de TI, com foco em diagnóstico e isolamento
de problemas em um computador com Windows 10.

## Problema
Lentidão geral no sistema operacional durante o uso diário.

## Diagnóstico
Após análise de armazenamento, inicialização, processos e desempenho,
foi identificado alto consumo de memória RAM.

A maior parte do consumo estava relacionada a processos essenciais
do próprio sistema operacional, que não podem ser desativados.

## Causa raiz
Limitação de hardware (4 GB de memória RAM).

## Solução aplicada

- Limpeza de arquivos desnecessários
- Otimização da inicialização
- Manutenção dos processos essenciais do Windows

## Aprendizado
A experiência reforçou a importância de identificar a causa do problema,
evitando soluções extremas como aplicada desnecessária.
